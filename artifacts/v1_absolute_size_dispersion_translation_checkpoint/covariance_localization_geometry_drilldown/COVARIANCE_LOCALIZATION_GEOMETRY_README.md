# V1 covariance-localization geometry drill-down

## Question

Why does conditional RF covariance appear to localize session `760345702`, while
session `798911424` has an annular translation objective? In particular, is that
difference generated by the covariance descriptors or by the penalty for moving
cells outside the population template's support?

## Result

The geometry is driven by covariance-feature mismatch, not template coverage.

| Session | Full optimum (az, el) | total vs mismatch rho | total vs coverage rho | coverage at optimum | cell-bootstrap p90 | block-jackknife max | shuffle p |
|---|---:|---:|---:|---:|---:|---:|---:|
| 760345702 | (+12, 0) deg | 1.000 | 0.007 | 97.8% | 4.5 deg | 2.8 deg | <0.001 (0/1000) |
| 798911424 | (-28, -16) deg | 0.977 | 0.075 | 98.4% | 59.4 deg | 59.4 deg | 0.042 (42/1000) |

For `760345702`, the total and mismatch-only optima coincide and the loss is a
compact two-dimensional basin. Conditional cell bootstraps and leave-one-physical-
block-out fits remain close to the full-data solution. This session therefore has
a covariance pattern that can identify a particular translation under the present
template and estimator.

For `798911424`, the total and mismatch-only optima also coincide, but low loss
occupies a broad ring with fitted radius about 30.0 deg (circle-fit RMSE 3.5 deg).
Resamples move around this ring and can differ from the selected full-data grid
optimum by about 59 deg. Its covariance pattern contains nonrandom population-level
structure, but that structure principally identifies a region/radius rather than
a unique azimuth/elevation translation.

The exact-support shuffle evidence for `798911424` is borderline (`p=0.042`) even
with 1,000 permutations. It should not be summarized as robust absolute
localization: a nonrandom descriptor-location relationship and a uniquely
identified translation are different claims.

## Important limitation

The bootstrap and block jackknife reuse the conditional-covariance descriptor
estimated from the full session. They quantify uncertainty in matching those
descriptors to the population template, not uncertainty in estimating the local
covariance descriptors themselves. A fully nested resample would recompute local
covariance after each cell/block resample.

The apparent annulus reaches the +/-30 deg search boundary, so the topology counter
does not report an enclosed hole. The radial profile and migration of resampled
optima are the more informative diagnostics here.

## Reproducibility

The script uses independent deterministic random streams for the shuffle null and
the conditional bootstrap, so changing the number of null permutations cannot
change the bootstrap draws.

## Smallest useful next step

Before scaling this into a registration method, run a fully nested covariance
bootstrap on these two sessions. It should test whether the compact basin of
`760345702` survives uncertainty in the covariance estimator itself, while
confirming that `798911424` remains directionally ambiguous. If that contrast
survives, apply the same identifiability diagnostics across the wider discovery
set and classify sessions as point-localizing, ridge/ring-localizing, or
uninformative rather than forcing one translation for every session.
